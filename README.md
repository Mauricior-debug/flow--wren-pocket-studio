# Wren Pocket Studio

A React Native app (Expo SDK 58) for planning and managing an app with Wren, the AI website and app architect.

The workspace stays on the device: accounts, projects, screen approvals, uploads, and development jobs. A remote model or coding agent is not called from this build, and a build is not marked successful until it is verified.

## Run

```bash
npm install
npx expo start
```

Open the project in Expo Go. The preview QR is in `wren-preview.json` after a publish.

Demo workspace on the sign-in screen: `alex@wren.studio` / `Wren1234`.

## Screens

Splash, Onboarding, Sign Up, Sign In, Password Reset, Terms, Privacy, Home, Projects, Create, Assets, Settings, App Builder, Project, Design studio, Screen review, Development job, Planning chat, Share and deploy, Notifications, Edit profile, Change password, Notification preferences, Privacy and data, App preferences.

Sheets: voice note, new project, Google account, pickers, delete confirmation.
