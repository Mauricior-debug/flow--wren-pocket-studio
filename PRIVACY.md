# Privacy Policy

Draft for Wren Pocket Studio. This is the policy the app describes. The store listing should point at a hosted copy. Until that page exists, the placeholder URL in the app config is `https://wren.studio/privacy`. The same text is available inside the app.

## Who this is for

Wren Pocket Studio is a mobile studio for planning, designing, and tracking an app or website. The account and the projects live on the device.

## Information stored on the device

- Name, email, and a salted hash of the password. The password itself is not stored.
- Profile photo, if you add one.
- Project briefs, screen approvals, jobs, and in-app notifications.
- Files you attach: photos, documents, archives, voice notes, and 3D model files such as GLB.
- Optional usage notes, only if you turn that switch on. They stay on the device.

## Phone access

- **Photos and camera.** Used when you choose a profile photo or a project reference. The app does not read the library in the background.
- **Microphone.** Used only while you hold the voice control to describe a project. Recordings stay on the device. The app does not turn speech into text on a server.
- Location, advertising identifiers, tracking, and push notifications are not requested.

## What is not connected

Provider API keys are not shipped in the app. A remote model or a coding agent is used only when an account for that service is connected outside this build. Until then, planning stays on the device and a development job stays queued. The app does not call a build or a deployment successful unless it has been verified.

## Sharing

There is no advertising and no sale of personal information. A share link or embed code is created on the device for you to copy. Sending it is your action.

## Your choices

From Privacy & Data you can export a JSON copy of the workspace, clear notifications, or delete the account. Deleting removes the account and its projects from the device.
